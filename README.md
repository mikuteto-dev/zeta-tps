# Zeta tok/s

[zeta](https://zeta-ai.io) の Web 版で、AI の返信の生成速度を入力欄の左上に表示する Chrome 拡張機能です。

![入力欄の左上に生成速度を表示](docs/screenshot.png)

```
150.2 tok/s · TTFT 2.8 s · 307 tok · 4.7 s
```

| 項目 | 内容 |
| --- | --- |
| `tok/s` | 最初のチャンクから最後のチャンクまでの生成速度 |
| `TTFT` | 送信から最初のトークンが届くまでの時間 |
| `tok` | 返信のトークン数（推定） |
| `s` | 送信から最後のチャンクまでの合計時間 |

生成中も値が更新されます。

## インストール

1. このリポジトリを clone する
2. `chrome://extensions` を開き、デベロッパー モードをオンにする
3. 「パッケージ化されていない拡張機能を読み込む」で clone したディレクトリを選ぶ

ビルドは不要です。依存パッケージもありません。

## 仕組み

- `tps.js` を `world: "MAIN"`・`run_at: "document_start"` で読み込み、`window.fetch` をラップします
- `content-type: text/event-stream` のレスポンスを複製して読み、SSE の `data:` 行の JSON から `text` キーの文字列を集めます。`request` を含むキーの下は除外します
- 累積テキストでも差分でも処理できるように、新しいテキストがそれまでのテキストで始まれば置き換え、そうでなければ追記します
- 表示位置は、画面に見えている最後の `textarea` から祖先をたどり、背景色を持つ最初の要素（入力欄）を基準に決めます。チップの背景色と影は入力欄の計算済みスタイルからコピーします

API のパスやクラス名に依存しないので、zeta の UI や API が変わっても動き続けやすい作りです。

## 制約

- トークン数は推定です。zeta のモデルのトークナイザーは公開されていないので、ASCII は 4 文字で 1 トークン、それ以外は 1 文字で 1 トークンとして数えています
- 表示するのは最新の返信 1 件分です。ページを再読み込みすると消えます
- Firefox では `world: "MAIN"` を使うため 128 以降が必要です（動作は未確認）
